## TL;DR

1. Open the site. First visit → you see the attract mode loop.
2. Press any key / tap / click to reach the main menu.
3. **Fight The Machine** (1P vs AI) — sign up with a display name + email, pick difficulty, play.
4. **Betray a Friend** (2P local) — share a keyboard, no signup.
5. First side to **7 points** wins.
6. Losses to the AI are recorded. So are wins. The leaderboard keeps the receipts.
